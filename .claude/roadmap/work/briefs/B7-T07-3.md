# Brief B7-T07-3 (ui): live riser networks of all open documents

Read .claude/roadmap/rules.md first. Escalation rule: if reality differs from this brief (a file, a signature, an event order), stop and return NEEDS_CONTEXT. Do not work around it. No `window.confirm`. Do not run prettier. No `pnpm add`.

## GOAL
New rule: for every document that is OPEN in the app, its LIVE riser networks count in the building flow, saved or not. For a document that is not open, the stored summary counts as before. Today only the active document is live. So an edit of one level reaches the other levels only after a save. Fix this with a session-only overlay in the ui layer: `Map<projectUuid, RiserNetworkSummary[]>`. Never write it to a store or a file. No format change.

## CONTEXT
Done before this brief (already in the worktree, built into dist when you run `pnpm --filter @mepapp/core build` and `pnpm --filter @mepapp/render build`; run both builds first):
- core: `solveBuildingFlow(file, summaries, live?: RiserNetworksLive | readonly RiserNetworksLive[])`. A live entry wins over the stored summary of its projectUuid and also works when there is no stored summary.
- render: `scene.exportProjectOf(documentId): ProjectDocument | null` exports any open document (the active one or not). `scene.getDocuments(): DocumentSummary[]` gives `{ id, projectUuid, ... }` for each open document. Event `documentsChanged` (payload `DocumentSummary[]`) fires after a document is closed or opened. Event order facts: `activateDocument(id)` sets the new active id BEFORE it emits `documentActivated`, so at that event `exportProject()` is already the NEW document. `closeDocument` of the active document emits `documentActivated` first, then `documentsChanged`; at `documentActivated` the removed document is already gone from the scene (`exportProjectOf` gives null).

## EXACT SHAPES
1. `riserFlowSync.ts`
```ts
/** The live riser networks of the open documents. Session only: never stored. Key: projectUuid. */
export class LiveRiserOverlay {
  /** Counts each change. */
  version = 0;
  set(projectUuid: string, networks: RiserNetworkSummary[]): boolean   // true when it differs (compare with JSON.stringify of the stored value); bumps version
  delete(projectUuid: string): boolean                                  // true when an entry was removed
  retain(keep: ReadonlySet<string>): boolean                            // removes entries not in keep; true when any removed
  clear(): boolean
  list(): RiserNetworksLive[]                                           // sorted by projectUuid, so the order is stable
}
```
(import `RiserNetworksLive` from `@mepapp/core`.) `computeRiserFlow` gets one more optional argument `others?: readonly RiserNetworksLive[]`. It builds `const lives = [{ projectUuid, riserNetworks: liveNetworksOf(fittingIds) }, ...(others ?? []).filter((item) => item.projectUuid !== projectUuid)]` and calls `solveBuildingFlow(file, summaries, lives)`. Everything else in the function stays (the null returns, `liveNetworksOf` called exactly once).

2. `useRiserFlowInputs.ts`: the hook returns `{ flow: RiserFlowState | null; live: RiserNetworksLive[] }` (export an interface `RiserFlowInputsResult`). Add:

- In `run`: pass `others: overlay.current.list()` to `computeRiserFlow`, and wrap `liveNetworksOf` so that the networks it builds are also stored: `(ids) => { const networks = buildRiserNetworks(scene.exportProject(), ids); overlay.current.set(uuid, networks); return networks; }` where `uuid` is `scene.getProjectUuid()`. When `computeRiserFlow` returns null and the file has risers and the active uuid is not null, call `overlay.current.delete(uuid)`; hmm, no: leave the overlay alone in that case (no capture) except for the file rules below. Call `publishLive()` at the end of `run` (also in the early return branches that follow a capture).
- File rule, in `run` before the early return for unread summaries: keep `const capturedFile = useRef<BuildingFile | null | undefined>(undefined)`. When `live.current.file !== capturedFile.current`: set it; if the file is null or has no risers, `overlay.current.clear()`; else for each document of `scene.getDocuments()` call `captureDocument(scene, doc.id, doc.projectUuid)` and then `overlay.current.retain(new Set(open project uuids))`.
