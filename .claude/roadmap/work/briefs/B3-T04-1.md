GOAL: Two pure helper modules for the "Add PDFs and assign pages" pane of the Manage Buildings dialog: `buildingPdfInfo.ts` (read the page count and the project id of a PDF) and `buildingSheets.ts` (group the PDFs of a building and its pending PDFs into rows), each with vitest tests.

CONTEXT: The dialog edits a `BuildingFile` (types in `packages/core/src/building.ts`: `BuildingFile`, `BuildingSheet`, `SheetLocation`; edit functions in `packages/core/src/building-edit.ts`: `addSheets`, `moveSheet`, `removeSheet`, type `NewSheetPage`). A PDF the user adds has pages that are "unassigned" until the user picks a level; unassigned pages are NOT stored in the file (decision D-B-17 A), the dialog keeps them in React state as `PendingPdf`. A sheet is one page of one PDF on one level. The id of a document lives in its embedded file `mepapp-project.json` (field `projectUuid`); `readProjectUuidFromJson(text): string | null` is in `@mepapp/core` (`packages/core/src/project-uuid.ts`). The engine interface is in `packages/pdf-engine/src/index.ts` (`PdfEngine.openDocument(bytes)`, `PdfDocumentHandle.getPageCount()`, `getEmbeddedFile(name): Promise<Uint8Array | null>`, `close()`). Same style as `packages/ui/src/rebuildSummaries.ts` (read it for the embedded-file name constant and the stub engine in `rebuildSummaries.test.ts`).

2. `packages/ui/src/buildingSheets.ts` and `packages/ui/src/buildingSheets.test.ts`:
```ts
import type { BuildingFile, BuildingSheet, NewSheetPage, SheetLocation } from '@mepapp/core';
export const COLLAPSE_AFTER_PAGES = 20;
export interface PendingPdf { fileName: string; path?: string; sizeBytes: number; pageCount: number; projectUuid: string | null }
export interface PageRow { pageIndex: number; sheet: BuildingSheet | null }
export interface PdfGroup {
  key: string;                      // pdfGroupKey(...)
  fileName: string;
  path?: string;
  projectUuid: string | null;
  sizeBytes?: number;
  /** Pages in the PDF when known (a pending PDF); for a PDF known only from sheets: highest assigned pageIndex + 1. */
  pageCount: number;
  /** Pending PDF: one row per page 0..pageCount-1 (sheet null when unassigned). Sheets-only PDF: one row per sheet, sorted by pageIndex. */
  rows: PageRow[];
  pending: boolean;
  /** True when pageCount > COLLAPSE_AFTER_PAGES. */
  collapsedByDefault: boolean;
}
/** 'u:<projectUuid>' when the id is known, else 'p:<path>' when the path is known, else 'f:<fileName>'. */
export function pdfGroupKey(projectUuid: string | null, path: string | undefined, fileName: string): string;
/** Pending PDFs first (in the order given), then the PDFs that only the sheets know (in the order of first sheet). A sheet joins the group with the same key; a pending PDF and sheets with the same key are one group (pending: true). */
export function groupPdfs(file: BuildingFile, pending: readonly PendingPdf[]): PdfGroup[];
/** The file name as it is when pageCount is 1 ('A101.pdf'), else '<fileName> p<pageIndex+1>' ('A101.pdf p2'). */
export function sheetDisplayName(fileName: string, pageIndex: number, pageCount: number): string;
/** The NewSheetPage for addSheets: projectUuid and location { fileName, path (only when defined), sizeBytes (only when defined) } from the group, displayName from sheetDisplayName. */
export function newSheetPage(group: PdfGroup, pageIndex: number): NewSheetPage;
/** True when two pending entries name the same PDF (same pdfGroupKey). */
export function isSamePdf(a: PendingPdf, b: PendingPdf): boolean;
/** How many pages in total and how many assigned over the groups, for a hint line: { pdfs, pages, assigned }. Pages of a sheets-only group count as assigned pages. */
export function pdfTotals(groups: readonly PdfGroup[]): { pdfs: number; pages: number; assigned: number };
```
Tests: each function; a pending PDF with 3 pages and a sheet on page index 1 gives 3 rows with the sheet on row 1; sheets-only group sorted by pageIndex; pending first; key preference (id over path over file name); `collapsedByDefault` false at 20 pages and true at 21; `newSheetPage` leaves out `path` and `sizeBytes` when undefined; `displayName` single and multi page.
