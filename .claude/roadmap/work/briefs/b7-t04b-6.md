Read .claude/roadmap/rules.md first.

GOAL: When one segment is selected and its network holds a riser fitting of the open level, the Properties panel shows one hint line under its capacity rows that says where the rest of the building is: at the riser fitting.

CONTEXT: The journey test found a gap. A duct that ends at a riser shows "Solved capacity 500". EXACT SHAPES:
```ts
import type { BuildingFile, Riser } from '@mepapp/core';

/** The risers that have a member on sheetId whose fittingId is in fittingIds. File order, each riser once. */
export function risersOfNetwork(file: BuildingFile, sheetId: string, fittingIds: readonly string[]): Riser[]

/** null for no name. One name: `This segment is on the network of riser R1. Select the riser fitting to see the connected total.` Several: `This segment is on the network of risers R1, R2. Select a riser fitting to see the connected total.` */
export function segmentRiserHint(names: readonly string[]): string | null
```
App.tsx (after the `riserLines` memo; same dependency style):
```ts
const segmentRiserHint = useMemo(() => {
  const file = buildingHook.building?.file;
  const scene = sceneRef.current;
  if (!file || !riserFlow || !scene || !selectedSegment) return null;
  const { segments, fittings, portGroups } = scene.getConnectivity();
  const network = computeNetworks({ segments, fittings, portGroups }).find((item) => item.segmentIds.includes(selectedSegment.id));
  if (!network) return null;
  const names = risersOfNetwork(file, riserFlow.sheetId, network.fittingIds)
    .filter((riser) => (riserFlow.flow.risers[riser.id]?.spans.length ?? 0) > 0)
    .map((riser) => riser.name);
  return segmentRiserHint(names);
}, [buildingHook.building?.file, riserFlow, selectedSegment]);
```
