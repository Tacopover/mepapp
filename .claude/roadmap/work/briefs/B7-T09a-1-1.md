# Brief B7-T09a-1-1: the helper `highestFlow` (core)

Read .claude/roadmap/rules.md first. Work only in /root/MepApp/.claude/worktrees/buildings-b7. Use absolute paths. No heredocs, no chained Bash commands.

## GOAL

Add a pure helper `highestFlow(nodes, edges)` that gives, for each edge and node of a tree, the highest value over all possible sources. Add tests with exact numbers.

## CONTEXT

A tree has nodes with `own` (demand) and `roots` (count of possible sources at the node). For one source `r`, an edge gets the demand of the side that does not hold `r`. The highest value of an edge is the maximum over all `r` with roots above 0. This must run in O(N), with no recursion (a chain of 20000 nodes must work). The result must not depend on the order of the input.

Algorithm:

1. `T` = sum of `own`. `K` = sum of `roots`.
2. Check the graph is one tree: exactly one connected component and edges = nodes - 1. Otherwise return null. Empty input returns null. Edges that name an unknown node: return null. Duplicate node ids: return null.
3. Walk from the first node (sorted by id) with an explicit stack. Record parent, the edge to the parent, and the walk order. Sort neighbours by id so the walk is deterministic (the result does not depend on it, but keep it stable).
4. In reverse walk order compute `sub[n]` (sum of `own` in the subtree of n) and `rootsSub[n]`.
5. For each edge between parent p and child c: side C = `{ demand: sub[c], roots: rootsSub[c] }`, side P = `{ demand: T - sub[c], roots: K - rootsSub[c] }`. Edge value = the highest of: `sub[c]` if side P has roots above 0; `T - sub[c]` if side C has roots above 0. If neither: null (this means K is 0). `sides[edgeId]` = `{ a, b }` where `a` is the side that holds the edge's node `a` (so `a` is side C if the child is node `a`, else side P).
6. Node value: for each edge at the node, take the demand of the node's own side of that edge when the OTHER side has roots above 0. For a node with `roots` above 0, also take `T`. The node value is the highest of these. Null when there is no candidate.

Check by hand: Example 5 level 1, node RF1 has edges s1 (RF1-F; RF1 side 250, F side has root O1: candidate 250), below (RF1 side 650, other side root 1: 650), above (RF1 side 600: 600). Value 650. Node F: edge `so` (F-O1): F side 750, O1 side has root: 750. Node O1: roots 1, so T = 750.

## EXACT SHAPES

```ts
export interface HighestNode { id: string; own: number; /** The number of possible sources at this node. */ roots: number }
export interface HighestEdge { id: string; a: string; b: string }
export interface HighestSide { demand: number; roots: number }
export interface HighestResult {
  /** Sum of `own` over all nodes. */
  total: number;
  /** Sum of `roots` over all nodes (K). */
  roots: number;
  /** Highest value of each edge: the demand of the side that holds no source. Null when K is 0. */
  edge: Record<string, number | null>;
  /** Highest value of each node (see 3.3 step 6). Null when none. */
  node: Record<string, number | null>;
  /** The two sides of each edge. `a` is the side that holds node `a`. */
  sides: Record<string, { a: HighestSide; b: HighestSide }>;
}
/** Null unless the graph is one tree: exactly one connected component and edges = nodes - 1. No recursion. The result does not depend on the order of the input. */
export function highestFlow(nodes: readonly HighestNode[], edges: readonly HighestEdge[]): HighestResult | null;
```
