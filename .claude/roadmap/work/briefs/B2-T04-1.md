EXACT SHAPES
```ts
export type TakeoffScope = { kind: 'building' } | { kind: 'level'; levelId: string };
export interface TakeoffSheetStatus { sheetId: string; state: 'ok' | 'no-summary' | 'old-summary' | 'pdf-missing-using-summary' | 'pdf-no-access-using-summary' | 'unreadable' }
export function buildBuildingTakeoff(args: {
  building: BuildingFile;
  scope: TakeoffScope;
  summaryOf: (projectUuid: string) => SheetSummary | undefined;
  statusOf: (sheet: BuildingSheet) => { state: 'ok' | 'missing' | 'no-access'; sizeBytes?: number; modifiedMs?: number };
}): { tables: QuantityTable[]; warnings: string[]; sheets: TakeoffSheetStatus[] };
```
(`TakeoffScope` and `TakeoffSheetStatus` may be exported from building-takeoff.ts. The plan listed them under sheet-summary.ts; put them in building-takeoff.ts and report that.)
`'unreadable'` stays in the type for the caller; this function never returns it.

Steps:
1. Sheets of the scope: Building = all sheets; Level = sheets with that `levelId` (unknown levelId gives no sheets). Order: by index of the level in `building.levels`, then by order in `building.sheets`. A sheet whose level is not found sorts last (cannot happen after parse).
2. For each sheet in order, with `label = sheet.displayName`:
   - `projectUuid === null`: warn `<label>: the document has no id yet. Open it in MepApp and save it.`; status `no-summary`; left out.
   - `summaryOf(uuid)` undefined: warn `<label>: no saved summary. Open the file in MepApp and save it, or use Rebuild summaries. Left out.`; status `no-summary`; left out.
   - Otherwise `status = statusOf(sheet)`, date = first 10 characters of `summary.savedAt`:
     - `missing`: state `pdf-missing-using-summary`; warn `<label>: PDF not found. Using the summary saved <date>.`
     - `no-access`: state `pdf-no-access-using-summary`; warn `<label>: MepApp may not read the PDF (no access). Using the summary saved <date>. Use Grant access in Manage Buildings.`
     - `ok`: old when (`sizeBytes` is a number and differs from `summary.sourceSizeBytes`) or (`modifiedMs` is a number and is greater than `summary.sourceModifiedMs`): state `old-summary`; warn `<label>: the PDF changed after the summary was saved (<date>). The rows may be old.` Else state `ok`.
     The rows of the summary are used in all these cases.
   - Copy each warning of the summary as `<label>: <warning>`, except a warning that starts with `Page <n> ` where n is not `sheet.pageIndex + 1` (pages not in this scope are not warned about).
   - Rows: from each table of the summary keep only rows whose cell in the `Page` column equals `sheet.pageIndex + 1` (a table without a `Page` header keeps no rows). Skip a table with no kept rows. Provenance: `{ building: building.name, level: <level name>, sheet: label, document: sheet.location.fileName }`.
3. `tables = mergeQuantityTables(parts)`.
4. Circuit across levels: in the merged `Terminals` table (if present), find the columns `Circuit`, `Document`, `Level`. Group by (Document, Circuit) for rows with a non-null Circuit. If a group has more than one distinct Level, warn `Circuit <label> has terminals on levels <a>, <b>. No vertical cable length is counted.` Level names in the order of `building.levels`, joined by ", ". Order of these warnings: first appearance in the table. Put them after the per-sheet warnings.
5. `warnings` order: per-sheet warnings in sheet order, then circuit warnings. `sheets`: one status for each in-scope sheet, same order.
