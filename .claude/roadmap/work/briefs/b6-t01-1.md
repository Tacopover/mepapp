## EXACT SHAPES
Band markup (inside BuildingSection, first):
```tsx
<div className="mep-reconnect" data-testid="reconnect-band">
  <p className="mep-hint" data-testid="reconnect-hint">{reconnectHint(needed.length)}</p>
  <button type="button" data-testid="reconnect-pdfs" aria-label="Reconnect PDFs" title={reconnectTooltip(levelId !== null)} onClick={() => void reconnect()}>Reconnect PDFs…</button>
</div>
```
The button is never disabled. `reconnect()`:
```ts
const needed0 = needed; // snapshot before the pick
let opened;
try { opened = await fileAccess.openFiles(BUILDING_PDF_TYPES); }
catch (err) { onNotice(`Could not open the file picker: ${(err as Error).message}`, true); return; }
if (opened.length === 0) return;            // cancel = no message
rememberFiles(opened);
// build scopeKeys from `shown`, buildingKeys from file.sheets (only sheets with sizeBytes)
const result = reconnectResult({ needed: needed0, picked: opened.map(o => ({ name: o.file.name, size: o.file.size })), scopeKeys, buildingKeys, isFound: (n) => canOpenCached?.(n.sheet) === true, isAmbiguous: (n) => isAmbiguous?.(n.sheet) === true, levelScope: levelId !== null });
onNotice(result.text, result.error);
```
Guard against an unmounted pane is not needed (onNotice is a plain callback).

Texts (word for word):
- `reconnectHint(1)` = `1 PDF needs a file before it opens. Choose it again.`; `reconnectHint(n>1)` = `${n} PDFs need a file before they open. Choose them all in one step.`
- `reconnectTooltip(true)` = `Choose the PDF files of this level. The app finds the sheets by file name and size. No sheet is added or changed.`; `(false)` the same with `this building`.
- `reconnectResult`, parts joined by one space, in this order (a zero part is left out):
  1. Found: if every needed PDF is found: N=1 -> `Found the PDF.`, N>1 -> `Found all ${N} PDFs.` Otherwise `Found ${F} of ${N} PDFs.` (N=1: `Found ${F} of 1 PDF.`). If F=0 and NO picked file has a key equal to the key of a needed PDF, add after it: `None of the ${P} files you chose has the same name and size as a PDF of the sheets here.` (P=1: `The file you chose does not have the same name and size as a PDF of the sheets here.`)
  2. Missing (only when not all found): `Missing: A.pdf, B.pdf.` Unique file names in the order of `needed`. At most 3 names; more than 3 -> `Missing: A.pdf, B.pdf, C.pdf and ${k} more.`
  3. Two files: needed PDFs that are not found, are ambiguous (`isAmbiguous`) AND have a picked file with the same key. Unique names: `For C.pdf you chose two different files with the same name and size. The app cannot tell which one to use. Use Choose file… on its row.` (several: `For C.pdf, D.pdf you chose two different files ...`).
  4. Other levels (only when `levelScope`): picked files whose key is not in `scopeKeys` but is in `buildingKeys`: count c -> c=1 `1 file is for another level.`, else `${c} files are for other levels.`
  5. Not used: picked files whose key is in neither `buildingKeys`... (key not in `buildingKeys`): c=1 `1 file was not used.`, else `${c} files were not used.`
  `error` = true only when F = 0 and N >= 1 (zero found).
- Use the `…` character (U+2026) exactly as written.
