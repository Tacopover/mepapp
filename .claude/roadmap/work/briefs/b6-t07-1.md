Hints (spec 6.2 table "Band hint"), in this order of the rules; an empty need or saved count removes the part:
- `canStore` false: `need >= 1` -> `reconnectHint(need)` (unchanged T01 text); else `changedPdfs >= 2` -> the changed hint; else null. `menu` null.
- `canStore` true: not `checked` -> null. `busy` -> hint `Looking for PDFs in {Folder or 'the folder'}…`, `menu` null, `reconnectDisabled` true.
- `saved === 0 && need === 0`: `changedPdfs >= 2` -> changed hint (with the menu of the folder state), else null.
- no folder, `saved >= 1`: `1 PDF is saved in this browser. Click Reconnect PDFs… to open it.` / `{P} PDFs are saved in this browser. Click Reconnect PDFs… to open them all.`, plus ` ` + need sentence when `need >= 1` (`needSentence`, existing).
- no folder, `saved === 0`: `1 PDF needs a file before it opens. Click Reconnect PDFs… to choose the folder or the file.` / `{N} PDFs need a file before they open. Click Reconnect PDFs… to choose the folder or the files.`
- folder stored, access 'prompt', `saved >= 1`: `1 PDF is saved in this browser. Click Reconnect PDFs… and use the folder {Folder} to open it.` / `{P} PDFs are saved in this browser. Click Reconnect PDFs… and use the folder {Folder} to open them.` (spec says "to open them" for P > 1: use the spec text of that row), plus the need sentence.
- folder stored otherwise (granted, or prompt with `saved === 0`), `need === 0` -> changed hint or null. Else: `1 PDF is not in the folder {Folder}. Click Reconnect PDFs… to choose the file or another folder.` / `{N} PDFs are not in the folder {Folder}. Click Reconnect PDFs… to choose the files or another folder.`
- changed hint: `{K} PDFs changed after they were added. Click Reconnect PDFs… and choose the new files.`
The first menu item label for access 'prompt' with `saved === 0` is `Use the folder {Folder}`; for 'granted' it is `Look in {Folder} again`.
