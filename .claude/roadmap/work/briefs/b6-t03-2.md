## GOAL
When a PDF with a `FileSystemFileHandle` target is given to the app, store the handle in the `PdfHandleStore` (only when `store.available`, the open building exists and the platform is not desktop, `fileAccess.readPath === undefined`). When a building opens, load the stored keys. `canOpenCached` answers from the cache OR the stored keys. A click on "Open" of a row with a stored handle opens the file through the handle (permission, getFile, size check). A failure shows a notice, keeps or deletes the handle (see pdfHandles.ts), and the file picker opens at once for that sheet. Without a store (Firefox, Safari, desktop, no prop) nothing changes.
