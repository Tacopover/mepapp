# Brief B3-T12b-2: Open of a sheet after Save must not open a second tab

Read .claude/roadmap/rules.md first. Work only in /root/MepApp/.claude/worktrees/buildings-model. Do not run git commit.

## GOAL
`openPdfFile` in App.tsx matches an open document only by `fileKey = name:size:lastModified`. A Save changes the size and the modified time of the file on disk, but the open document keeps its old fileKey. So "Open" on a sheet after a Save opens the file a second time (duplicate tab). Add a second match: by file path, when the new open has a path and an open document has a target with the same path.

## CONTEXT
- `packages/ui/src/App.tsx` line ~703 `openPdfFile(file, fileTarget)`. `fileTargetsRef = useRef(new Map<string, FileTarget>())` (documentId -> target; set at open, and at Save line ~931). `pathOfTarget(target)` is in `packages/ui/src/buildingPdfInfo.ts` (returns `target?.path`).
- `openSheet` (line ~800) calls `await openPdfFile(...)`, then looks up the document again with `findDocumentByFileKey(fileKey)` of the file it just read. That lookup fails when the match was by path.
- The scene has `getDocuments()` returning documents with `id`, and `activateDocument(id)`.

## EXACT SHAPES
New pure helper:
```ts
/** The id of the open document whose file target has this path. undefined when the path is undefined or no open document matches. The first match in `openIds` order wins. Paths compare equal after '\\' becomes '/' and case folds, because Windows paths are case-insensitive. */
export function findOpenDocumentByPath(
  targets: ReadonlyMap<string, { path?: string }>,
  openIds: readonly string[],
  path: string | undefined,
): string | undefined
```
Tests: match; no path -> undefined; a target whose document is not in openIds is ignored; backslash vs slash and case-insensitive equal; different path -> undefined.

In `App.tsx`:
- Change `openPdfFile` to return `Promise<string | null>`: the document id that is now on screen for this file (existing match by fileKey, existing match by path, or the new document id), or null when nothing opened (task busy, error).
- After the fileKey check fails and before the busy check: `const byPath = findOpenDocumentByPath(fileTargetsRef.current, (sceneRef.current?.getDocuments() ?? []).map((d) => d.id), pathOfTarget(fileTarget));` If found: activate it, set the new fileTarget for it, `setStatus(\`Switched to already-open ${file.name}.\`)` (same text as today) and return it.
- `openSheet`: use the returned id instead of the second `findDocumentByFileKey` lookup. Keep the error return `{ ok: false, message: 'The file could not be opened. See the header for details.' }` when the id is null.
- Other callers (`handleOpenPdf`, the onOpenRequest queue, any more) ignore the return value; check with grep that every call still type-checks. Keep the `useCallback` dependency lists correct.
- Do not change the `fileKey` stored on the document.
