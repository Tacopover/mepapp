## 4 Already-assigned result (buildingSheets.ts)
Change `placeEntriesOnLevel` result to
```ts
{ file: BuildingFile; placed: number; already: number; sameLevel: number; elsewhere: { levelName: string; count: number }[] }
```
`already` stays the total (sameLevel + sum of elsewhere). A page that is already a sheet on `levelId` counts in `sameLevel`; on another level it counts in `elsewhere` grouped by the level (name from `file.levels`, `'another level'` when the level is unknown), in order of first appearance. The unknown-target-level result becomes `{ file, placed: 0, already: 0, sameLevel: 0, elsewhere: [] }`. Update existing tests.
Add and export pure text builders (with tests in buildingSheets.test.ts):
```ts
/** '' when nothing was already assigned. */
export function alreadyAssignedText(sameLevel: number, elsewhere: readonly { levelName: string; count: number }[]): string
```
 Output: one sentence per level, elsewhere first, joined by a space:
 - `2 pages are already on Level 1 and were not moved.` (singular: `1 page is already on Level 1 and was not moved.`)
 - same level: `3 pages are already on this level.` (singular: `1 page is already on this level.`)
```ts
export function addResultText(input: { levelName: string; placed: number; pdfCount: number; sameLevel: number; elsewhere: ...; skippedDuplicates?: number; failed?: readonly string[]; source?: string }): string
```
 Examples (exact):
 - placed 3, pdfCount 1 -> `Added 3 pages to Ground floor.`
 - placed 1, elsewhere [{Level 1, 2}] -> `Added 1 page to Ground floor. 2 pages are already on Level 1 and were not moved.`
 - placed 0, elsewhere [{Level 1, 2}] -> `Nothing added. 2 pages are already on Level 1 and were not moved.`
 - placed 5, pdfCount 2, source 'Plans' (folder) -> `Added 5 pages from Plans (2 PDFs) to Ground floor.`
 - skippedDuplicates 1 -> append ` 1 PDF was picked twice and skipped.` (plural: `2 PDFs were picked twice and skipped.`)
 - failed ['x.pdf'] -> append ` Could not read x.pdf.`
 - pdfCount > 1 without source -> `Added 5 pages (2 PDFs) to Ground floor.`
 Use `countLabel` from buildingLevels.ts where it fits.
