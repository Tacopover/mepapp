EXACT SHAPES
New file packages/ui/src/components/BuildingNameEditor.tsx:
```tsx
export interface BuildingNameEditorProps {
  name: string;
  /** Called with the trimmed, non-empty new name that differs from the saved name. */
  onRename: (name: string) => void;
  /** Quiet warning text under the name (two buildings with one name). */
  warning?: string | null;
  testId: string; // 'building-name-header' | 'building-name-pane'
  className?: string;
}
```
Behaviour: not editing: `<span className="mep-name-text" title={name} data-testid={`${testId}-text`}>{name}</span>` plus `<button type="button" className="mep-name-rename" data-testid={`${testId}-rename`} aria-label="Rename building" title="Rename building">Rename</button>`. Click: editing = true; draft = name; an `<input aria-label="New building name" data-testid={`${testId}-input`}>` replaces the text, takes the focus and selects all (effect). Enter: commit. Escape: cancel (stopPropagation, back to the text, the button takes the focus back). Blur: commit. Commit with an empty (after trim) draft: refuse. On Enter an empty draft keeps the input open and shows `<p role="alert" className="mep-hint mep-name-error">A building needs a name.</p>`; on blur an empty draft reverts to the saved name with no change. A draft equal to the saved name only closes the input. After a good commit call `onRename(trimmed)` and close. Show `warning` as `<p className="mep-hint mep-name-warning" data-testid={`${testId}-warning`}>` under the row when set and not editing. The input must not make the layout jump: width `min(28rem, 100%)`, same font as the text.
Header: replace the `<p className="mep-buildings-open-name">` with `<div className="mep-buildings-open-name"><BuildingNameEditor testId="building-name-header" name=... onRename={(n) => void building.update((f) => renameBuilding(f, n))} warning={duplicateWarning} /></div>` (keep the old class on the wrapper so the CSS keeps working; adapt CSS so the row is `display:flex; gap; align-items:center; min-width:0` and the name is cut with an ellipsis).
BuildingLevelsPane building view: put the editor as the first element of the section body under a small label row "Name" (class like the level field), `testId="building-name-pane"`, with `onRename={(n) => void update((f) => renameBuilding(f, n))}`.
Duplicate warning: add to packages/ui/src/buildingTree.ts (or buildings.ts, pick the one next to similar helpers) a pure `export function duplicateBuildingNameWarning(recent: readonly RecentBuilding[], file: BuildingFile): string | null` that returns `'Another building has this name.'` when a recent entry with another id has the same name (trim, case-insensitive), else null. Add unit tests in the matching .test.ts (same name other id; same id ignored; different case; none). Dialog passes the result as `warning` to the header editor.
