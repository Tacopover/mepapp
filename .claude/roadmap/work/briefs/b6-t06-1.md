## EXACT SHAPES
All names, types and rules are in the design file under "New and changed names". Implement exactly those. Details:
- `isChangedFile(file, name, size)`: true when some sheet has `location.fileName === name` and a defined `sizeBytes`, and no sheet has `fileName === name && sizeBytes === size`.
- `sheetGroupsOfName(file, name)`: sheets with that file name and a defined size, grouped by `sheetPdfKey` (import from `./buildingSheets.js`), order of first appearance.
- `scanPdfFolder`: the current code skips an entry when `!sizes.has(file.size)`. Instead collect it as a changed candidate in a second map by name (same dedupe: same size and same `lastModified` counts once). After the loop: for each name in the second map that has no key in `found` (no exact match for that name; compare by file name) -> if exactly one distinct candidate, push to `changed` (`{ key: pdfHandleFileKey(name, size), file, handle }`); if more than one, add the name to `changedAmbiguousNames`. Keep `matches`, `ambiguousKeys`, `capped`, `scanned` exactly as they are. Candidates count toward `maxItems` as before (they are already counted by `scanned`).
- The new `FolderScanResult` fields are required (not optional): update every existing test object that builds a `FolderScanResult` by hand, if any.
- `folderResultNotice`: new optional input fields `changedNames`, `changedMode`, `changedAmbiguousNames` as in the design. With `changedMode: 'found'` a needed PDF with a name in `changedNames` counts as found; with `'excluded'` it is removed from `needed` before the counts (total, found, missing). When the total after exclusion is 0 return null.
- `reconnectResult`: new optional input fields as in the design; same two modes; picked files whose name is in `changedNames` never count as "not used".
- `twoChangedText(names, source)`: `For {names joined by ', '} the folder has two different files with another size. The app cannot tell which one to use. Use Choose file… on its row.` (source 'folder') or `For {names} you chose two different files with another size. The app cannot tell which one to use. Use Choose file… on its row.` (source 'picked').
- Text functions: build the strings from spec 6.1, with the singular and plural cases the spec lists.
