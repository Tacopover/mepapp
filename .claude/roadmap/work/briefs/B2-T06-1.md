EXACT SHAPES
```ts
// rebuildSummaries.ts
export interface RebuildFailure { sheet: BuildingSheet; reason: string }
export interface RebuildResult { ok: number; failed: RebuildFailure[] }

export async function rebuildSummaries(args: {
  building: BuildingFile;
  engine: PdfEngine;
  read: (sheet: BuildingSheet) => Promise<File | undefined>;
  /** Why read() gave undefined, for the failure text. Default: 'the PDF could not be read'. */
  whyUnreadable?: (sheet: BuildingSheet) => Promise<string>;
  /** Name lookups for one project (its own custom stamps plus the library). */
  stampNames: (project: ProjectDocument) => { stampTypeName: (id: string) => string | null; stampImageName: (id: string) => string | null };
  store: BuildingStore;
  onProgress: (done: number, total: number, name: string) => void;
  signal: AbortSignal;
  now?: () => Date;
}): Promise<RebuildResult>;
```
Rules:
- Distinct documents: group `building.sheets` by `sheet.projectUuid`; sheets with `projectUuid === null` group by `location.path ?? location.fileName`. The first sheet of a group reads the file. `total` = number of groups; name = `sheet.location.fileName`.
- `onProgress(done, total, name)` is called before each document with `done` = documents finished so far, and once at the end with `done = total` and name ''. Check `signal.aborted` before each document; when aborted stop and return what was done.
- Per document, strictly one after another: `read(sheet)` (undefined -> failure with `await whyUnreadable(sheet)`), `engine.openDocument(new Uint8Array(await file.arrayBuffer()))`, `getEmbeddedFile('mepapp-project.json')`; null -> failure 'never saved in MepApp'; `loadProject(JSON.parse(new TextDecoder().decode(bytes)))`; `project.projectUuid` undefined -> failure 'the document has no id yet. Save it again in MepApp'; when `sheet.projectUuid` is not null and differs -> failure 'the file holds another document id'; `buildSheetSummary({ project, savedAt: now().toISOString(), sourceSizeBytes: file.size, sourceModifiedMs: file.lastModified, pageInfos from the handle, ...stampNames(project) })`; `store.writeSummary(project.projectUuid, JSON.stringify(summary))`. ALWAYS `handle.close()` in a finally, also after an error. Any thrown error becomes a failure with `(err as Error).message`. One failure per group is recorded against the first sheet of the group. `ok` counts documents.
App.tsx:
- Props: `pdfEngine?: PdfEngine;` and `onRebuildReady?: (run: ((read?: (sheet: BuildingSheet) => Promise<File | undefined>) => Promise<RebuildResult | undefined>) | null) => void;` with one-line doc comments.
- `handleRebuildSummaries(readOverride?)` (useCallback): returns undefined (and sets status 'Open a building first.') when `buildingStore` or `pdfEngine` is missing or the store has no building file. Otherwise parse the building (`parseBuildingFile(JSON.parse(json))`), default `read` = for a sheet with `location.path` and `fileAccess.readPath`: `(await fileAccess.readPath(path))?.file`, else undefined. Default `whyUnreadable`: with no path -> 'no path is stored for this PDF'; no `fileAccess.statPath` -> 'this platform cannot read a PDF by path'; else map the stat state: missing -> 'PDF not found', no-access -> 'MepApp may not read the PDF (no access)', ok -> 'the PDF could not be read'. `stampNames` = `(project) => stampNameLookups([...project.customStampDefinitions, ...userStampLibrary.definitions])`. `onProgress` sets status `Rebuilding summaries: ${done} of ${total}${name ? ` (${name})` : ''}`. At the end set status `Rebuilt ${ok} of ${total} summaries.` and, when some failed, append ` ${failed.length} failed: ${first.sheet.displayName}: ${first.reason}` (first failure only). Wrap in try/catch -> status `Failed to rebuild summaries: <message>`. Use a fresh `new AbortController().signal`. Do not use fileTaskRef.
- A `useEffect` that calls `onRebuildReady?.(handleRebuildSummaries)` and on cleanup `onRebuildReady?.(null)`.
