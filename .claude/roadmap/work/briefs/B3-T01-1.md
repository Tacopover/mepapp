GOAL: `@mepapp/core` has pure edit functions for a `BuildingFile` (levels and sheets) with tests.

CONTEXT: The Manage Buildings dialog (B3) edits a building file only through pure functions of core. `BuildingFile`, `BuildingLevel`, `BuildingSheet`, `SheetLocation` are in `packages/core/src/building.ts`. The validator there forbids a sheet whose `levelId` names no level, and forbids two sheets for the same document page (key `u:<projectUuid>#<pageIndex>` when projectUuid is a string, else `p:<location.path>#<pageIndex>` when the path is a string, else no key). Every function returns a NEW object and never mutates its input.

TARGETS:

EXACT SHAPES (import types from './building.js'):

```ts
export type BuildingEditError = 'unknown-level' | 'level-has-sheets';

export interface NewSheetPage {
  projectUuid: string | null;
  pageIndex: number;
  displayName: string;
  location: SheetLocation;
}

/** New level at the end. name is trimmed; a blank name becomes 'Level N' where N = levels.length + 1. elevationMm defaults to 0; a value that is not finite becomes 0. id defaults to crypto.randomUUID() (the optional last argument exists for tests). */
export function addLevel(file: BuildingFile, name: string, elevationMm?: number, id?: string): BuildingFile;
/** A blank (after trim) name or an unknown id returns the file unchanged. */
export function renameLevel(file: BuildingFile, levelId: string, name: string): BuildingFile;
/** A value that is not finite, or an unknown id, returns the file unchanged. Negative is allowed. */
export function setLevelElevation(file: BuildingFile, levelId: string, elevationMm: number): BuildingFile;
/** Moves the level to index toIndex (clamped to 0..levels.length-1) and keeps the order of the other levels. Unknown id: unchanged. */
export function moveLevel(file: BuildingFile, levelId: string, toIndex: number): BuildingFile;
/** Refuses when a sheet uses the level. */
export function deleteLevel(file: BuildingFile, levelId: string): { ok: true; file: BuildingFile } | { ok: false; error: BuildingEditError };
/** Adds one sheet per page at the end of sheets (sheet id = crypto.randomUUID()). A page whose document-page key (see CONTEXT) already has a sheet in the file, or appears twice in pages, is skipped and returned in skipped (the later one is skipped). A page with no key (projectUuid null and no location.path) is never skipped. Unknown levelId: error 'unknown-level'. */
export function addSheets(file: BuildingFile, levelId: string, pages: NewSheetPage[]): { ok: true; file: BuildingFile; skipped: NewSheetPage[] } | { ok: false; error: BuildingEditError };
/** Unknown ids: unchanged. */
export function moveSheet(file: BuildingFile, sheetId: string, levelId: string): BuildingFile;
export function removeSheet(file: BuildingFile, sheetId: string): BuildingFile;
/** Replaces location; when projectUuid is given (not undefined) also replaces projectUuid. Unknown sheet: unchanged. */
export function relinkSheet(file: BuildingFile, sheetId: string, location: SheetLocation, projectUuid?: string | null): BuildingFile;
/** Stable sort by elevationMm ascending. */
export function sortLevelsByElevation(file: BuildingFile): BuildingFile;
```

Tests (each function): add (default name, trimmed, blank, default elevation, custom id); rename (blank refused); elevation (negative ok, NaN refused); moveLevel (to front, to end, clamp, order of others kept); deleteLevel (refuses with 'level-has-sheets', works on an empty level, input not mutated); addSheets (two pages added in order, a page twice in one call skipped, a page that exists skipped with returned list, unknown level error, null-uuid pages with no path never skipped); moveSheet; removeSheet; relinkSheet (with and without projectUuid); sortLevelsByElevation (stable for equal elevations).
