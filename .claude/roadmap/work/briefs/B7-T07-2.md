# Brief B7-T07-2 (render): export the project of any open document

Read .claude/roadmap/rules.md first. Escalation rule: if reality differs from this brief, stop and return NEEDS_CONTEXT. Do not work around it.

## GOAL
The ui must read the live riser networks of a document that is no longer the active one (the user just switched away from it). Today `SketchScene.exportProject()` exports only the active document. Add a public method that exports a document by id.

## CONTEXT
`packages/render/src/scene.ts` around line 4608:
```ts
  exportProject(): ProjectDocument {
    return this.serializeDocument(this.doc);
  }

  getProjectUuid(): string | null {
    return this.doc.projectUuid;
  }
```
`this.documents` is the array of `SketchDocument` (each has `id`). `serializeDocument(doc)` is private and works for any document (it reads only the state of the document it gets). See `closeDocument` (line 1248) for the style of `this.documents.find(...)`.

## TARGETS
- `packages/render/src/scene.ts` only.

## EXACT SHAPES
Add directly after `exportProject()`:
```ts
  /** Like exportProject for any open document, active or not. null when no open document has this id. */
  exportProjectOf(documentId: string): ProjectDocument | null {
    const target = this.documents.find((d) => d.id === documentId);
    return target ? this.serializeDocument(target) : null;
  }
```
No other change. No new event.
