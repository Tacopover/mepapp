# Brief B3-T12b-1: add PDFs to the selected level, Open keeps the dialog

Read .claude/roadmap/rules.md first. Work only in /root/MepApp/.claude/worktrees/buildings-model. Do not run git commit.

## GOAL
1. "Add PDFs…" and "Add folder…" (BuildingSheetsPane) put the pages that are not yet sheets on the selected level at once. With no selected level (levelId null) the old behaviour stays: the PDFs wait under "Not placed" and `onAdded` fires.
2. "Open" on a sheet keeps the Building dialog open. The ask "Open the sheet anyway? The dialog closes." is removed (the dialog no longer closes).

## CONTEXT
- `packages/ui/src/components/ManageBuildingsDialog.tsx`: `openSheetNow` calls `onClose()` after `onOpenSheet`. `openSheetGuarded` asks first when pages wait (kind 'open-sheet'). `AskKind`/`ASK_BUTTON` already lost 'open-sheet' (done by lead with sed). `openSheetGuarded` is already renamed in the JSX props to `openSheetKeepOpen` (3 places); the function itself is not written yet.
- `packages/ui/src/components/BuildingSheetsPane.tsx`: `addFile` and `addFolder` read PDFs into `PendingPdf` entries, then call `pendingPdfs.add(...)` and `onAdded?.()`.
- `packages/ui/src/buildingSheets.ts` has `groupPdfs(file, pending)` (rows with `sheet === null` are pages not yet in the building), `newSheetPage(group, pageIndex)`, `isSamePdf`.
- `addSheets(file, levelId, pages)` from `@mepapp/core` returns `{ok:true,file,skipped}` or `{ok:false}`.
- The dialog passes `selectedLevel?.id ?? null` as the level (the node selected in the tree). The `update` function is `building.update`, signature `(change: (file: BuildingFile) => BuildingFile) => Promise<void>`.

## EXACT SHAPES
In `buildingSheets.ts` add (pure):
```ts
/** Puts the pages of the entries that are not yet sheets on the level. A page that is already a sheet stays where it is and is counted in `already`. An unknown level changes nothing. */
export function placeEntriesOnLevel(file: BuildingFile, entries: readonly PendingPdf[], levelId: string): { file: BuildingFile; placed: number; already: number }
```
Implementation: `groupPdfs(file, entries).filter(g => g.pending)`; for each group, rows with `sheet === null` -> `newSheetPage(group, row.pageIndex)`; rows with a sheet -> `already`. One `addSheets` call with all new pages; if `!result.ok` return `{ file, placed: 0, already: 0 }`. `placed` = pages count minus `skipped.length`.
