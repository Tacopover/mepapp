## EXACT SHAPES
`SheetRelink` gets (see the design for the doc comments):
```ts
  relinkWith: (sheet: BuildingSheet, origin: string, picked: OpenedFile) => Promise<void>;
  applyNewFile: (sheet: BuildingSheet, location: SheetLocation, projectUuid: string | undefined) => Promise<boolean>;
  isOtherDocument: (sheet: BuildingSheet, projectUuid: string | null) => boolean;
```
Refactor so `relink` = `openFile` + `relinkWith`; `applyRelink` = `applyNewFile` + the notice `Relinked {name}.` when true. `applyNewFile` returns false (after the existing refused notice) when the duplicate check or `relinkSheet` refuses. `isOtherDocument(sheet, projectUuid)` = `projectUuid !== null && sheetsOfSamePdf(file, sheet).some((o) => o.projectUuid !== null && o.projectUuid !== projectUuid)`. Behaviour of `relink`, `askFor`, `confirm`, `cancel` and `RelinkConfirm` does not change.

`useChangedFile.tsx` exports `ChangedOffer`, `ChangedFiles`, `useChangedFile`, `ChangedFileConfirm` with the signatures of the design. Details:
- State: `offer` (`useState`), `changedSheetIds` (`useState<ReadonlySet<string>>`), a ref with the current offer for `confirm`/`cancel`, the ref of the `afterUse`/`finish` callback of the offer.
- `read(opened)` = `engine === undefined ? { pageCount: null, projectUuid: null } : readPdfInfo(opened.file, engine)`. On error: `onNotice('Could not read {name}: {message}', true)` and skip the file.
- `buildItem(sheets, opened, info)`: `sheetIds = sheetsOfSamePdf(file, sheets[0]).map(id)`, `lostPages = pageCount === null ? [] : lostPageNumbers(<those sheets>, pageCount)`.
- `offerRow(sheet, opened, afterUse)`: when `!isChangedFile(file, opened.file.name, opened.file.size)` or `sheet.location.fileName !== opened.file.name` -> do nothing (return). Read the info. If `relinker.isOtherDocument(sheet, info.projectUuid)` -> `await relinker.relinkWith(sheet, 'sheets', opened)` and return (the old question). Else set the offer `{ scope: 'row', sheetId: sheet.id, items: [item] }` with `afterUse` kept.
- `offerFiles(opened, finish)`: take the files for which `isChangedFile` is true. Group by file name: more than one different file for a name (different size or `lastModified`) -> that name is "two candidates": not offered, the name goes to a list; the caller adds `twoChangedText(names, 'picked')` itself, so ALSO expose it: change the return value to `Promise<boolean>` as in the design, and put the two-candidate names into the answer `names`-independent field — keep the design signature; show the two-candidate text through `onNotice` (error false) when no other prompt remains, else append it to the `finish` text. For each remaining name: `sheetGroupsOfName(file, name)`; exactly one group, else skip (two PDFs with one name: add to the two-candidates list). Read the info. A different-document file is left out and named in the `finish` text: `{names} is a different document. Use Choose file… on its row.` (plural `are`). No items left -> return false. Else set the offer `{ scope: 'band', sheetId: null, items }` and return true.
- `confirm()` and `cancel()` as in the design. `confirm` for scope 'row' calls `afterUse(sheetWithNewSize, changedUseNotice(item))` where `sheetWithNewSize` = the sheet with `location` `{...sheet.location, fileName, sizeBytes: opened.file.size}` (the `file` prop may still be old). For scope 'band': `finish({ used: true, pdfs: items.length, sheets: sum of sheetIds.length, names })` -> `onNotice(text, error)`. Use a helper `locationOf(opened)` = `{ fileName, sizeBytes, ...(path from pathOfTarget(opened.target)) }` (like `relink()`).
- After a successful apply, call `remember?.([opened])` for each used item AFTER the building update, then clear the ids from `changedSheetIds`.
- `changedPdfCount` = number of distinct `sheetPdfKey` among the sheets of `file` whose id is in `changedSheetIds`.
- `ChangedFileConfirm`: markup as in the design (copy `RelinkConfirm` classes). `p.mep-hint` `role="status"` `data-testid="changed-confirm"` with `changedPromptText(offer.items)`. Buttons `data-testid="changed-confirm-yes"` and `changed-confirm-cancel`. Focus: `useEffect` that focuses the yes button on mount (`ref`). `onKeyDown` on the wrapper div: Escape -> `onNo()` and `stopPropagation()` (the dialog must not close).
