GOAL: The building controller computes a status for every sheet of the open building (file found, missing, no access, not stamped, no summary, old summary) and keeps it in `OpenBuilding.sheetStatus`.

CONTEXT: `packages/ui/src/buildingController.ts` already has `export type SheetStatus` and the field `sheetStatus: Record<string, SheetStatus>` on `OpenBuilding` (always `{}` today, three places set it: `adopt`, `loadInto`, and the type). `FileAccess.statPath?(path): Promise<{ state: 'ok' | 'missing' | 'no-access'; sizeBytes?: number; modifiedMs?: number }>` exists (desktop; absent on web). `packages/ui/src/quantitiesScope.ts` already has `statSheets(sheets, statPath)` (returns `Map<sheetId, SheetStat>`; a sheet with no path or no statPath gets `no-access`, so call it only for sheets WITH a path) and `readSummaries(store): Promise<{ summaries: Map<projectUuid, SheetSummary>; problems }>`. `SheetSummary` (core) has `savedAt` and `sourceSizeBytes`. `PathState` is exported by `@mepapp/platform`. The controller (class `BuildingController`) has `fileAccess`, `generation` (advances when the open building changes), `setBuilding(patch)`, `pendingWrites`, `writeChain`. `update()` writes in a chain; `writeLatest` has a `finally` that runs when a write ends.

TARGETS:
1. `packages/ui/src/buildingStatus.ts` (new, pure) and `packages/ui/src/buildingStatus.test.ts` (new):
```ts
import type { BuildingSheet } from '@mepapp/core';
import type { PathState } from '@mepapp/platform';
export type SheetStatus = 'ok' | 'pdf-missing' | 'no-access' | 'not-stamped' | 'no-summary' | 'old-summary' | 'copy-suspected';
/** state 'unknown' = the platform cannot probe the file (no path, or no statPath). */
export interface SheetProbe { state: PathState | 'unknown'; sizeBytes?: number }
/** missing -> 'pdf-missing'; no-access -> 'no-access'; else projectUuid null -> 'not-stamped'; no summary -> 'no-summary'; probe.sizeBytes known and different from summary.sourceSizeBytes -> 'old-summary'; else 'ok'. 'copy-suspected' is never returned here (reserved). */
export function sheetStatusOf(sheet: BuildingSheet, probe: SheetProbe, summary: { savedAt: string; sourceSizeBytes: number } | undefined): SheetStatus;
export function statusLabel(status: SheetStatus): string;
// ok 'File found' ; pdf-missing 'PDF missing' ; no-access 'No access to the PDF' ; not-stamped 'Not stamped yet. Open and save it in MepApp.' ; no-summary 'No summary yet' ; old-summary 'Summary is out of date' ; copy-suspected 'May be a copy of another file'
export function statusTone(status: SheetStatus): 'ok' | 'warn' | 'bad';
// ok -> 'ok'; no-summary, not-stamped, old-summary, copy-suspected -> 'warn'; pdf-missing, no-access -> 'bad'
```
Tests: every status via `sheetStatusOf` (including 'unknown' probe with a summary -> 'ok', unknown probe with no uuid -> 'not-stamped', size equal -> 'ok', size differs -> 'old-summary', missing wins over a null uuid, no-access likewise), every label and tone.
2. `packages/ui/src/buildingController.ts`: delete the local `SheetStatus` type and `export type { SheetStatus } from './buildingStatus.js'` plus an import for use. Add the method
```ts
/** Probes every sheet (statPath) and reads the summaries; stores the result in building.sheetStatus. Does nothing when no building is open. Ignores a result that a newer open of a building overtook (generation). Never throws: a failure leaves the old statuses and sets no message. */
async refreshSheetStatus(): Promise<void>
```
Algorithm: capture `building` and `generation`; `const withPath = file.sheets.filter(s => s.location.path !== undefined)`; `stats = await statSheets(withPath, this.fileAccess.statPath?.bind(this.fileAccess))` (when `statPath` is undefined every sheet gets probe `{state:'unknown'}`: skip the call); `const { summaries } = await readSummaries(building.store)` in a try/catch (failure -> empty map); for each sheet: probe = path undefined or no statPath ? `{state:'unknown'}` : `{ state: stat.state, sizeBytes: stat.sizeBytes }`; `summary = sheet.projectUuid !== null ? summaries.get(sheet.projectUuid) : undefined`; status = `sheetStatusOf(...)`. After the awaits, if `this.generation !== generation` return; `this.setBuilding({ sheetStatus })` (only when the record differs, `setBuilding` compares by identity so compare JSON first). Call `void this.refreshSheetStatus()` (a) at the end of `showBuilding`'s callers `loadInto` and `adopt` after `showBuilding`, (b) in `reload()` after a successful `setBuilding({ file, revision })`, (c) in `writeLatest`'s `finally` when `this.pendingWrites === 0`. Statuses of a sheet that is new since the last refresh are simply absent until the refresh ends: readers must treat a missing key as unknown.
3. `packages/ui/src/useBuilding.ts`: expose `refreshSheetStatus` like the other methods (add to the `Pick<...>` type, the memo object, and the returned object).
