GOAL: The Manage Buildings dialog edits the levels of the open building: name, elevation (mm), order, add, delete. Every change goes through `building.update(...)`.

CONTEXT: `ManageBuildingsDialog.tsx` shows the open building with the line "N levels, M sheets". `UseBuilding.update(change: (file: BuildingFile) => BuildingFile): Promise<void>` writes at once (optimistic) and reloads on a conflict. Pure edit functions are in `@mepapp/core` (`packages/core/src/building-edit.ts`): `addLevel(file, name, elevationMm?, id?)`, `renameLevel`, `setLevelElevation`, `moveLevel(file, levelId, toIndex)`, `deleteLevel(file, levelId)` (returns `{ok:true,file}` or `{ok:false,error}`), `sortLevelsByElevation`; they return the same object when nothing changes. `levelWarnings(file): string[]` is in `building.ts`. `NumberDraftInput` (`packages/ui/src/components/NumberDraftInput.tsx`) is a number box that keeps the user's text and calls `onCommit` for each valid number. A level that has sheets cannot be deleted. Elevation = height of the finished floor above a datum, mm, negative allowed.
