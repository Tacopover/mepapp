`sheetRowLine.ts`:
```ts
import type { SheetStatus } from './buildingStatus.js';
export interface RowLineInput {
  /** True in the web app (no readPath). A desktop row keeps the old lines. */
  web: boolean;
  status: SheetStatus | undefined;
  /** The sheet is open in the viewer. */
  opened: boolean;
  /** 1-based page number when the last open found that the page is not in the file, else null. */
  missingPage: number | null;
  /** The sheet is in ChangedFiles.changedSheetIds. */
  changed: boolean;
  /** The app can open the PDF now (canOpenCached: in the tab or stored). */
  canOpen: boolean;
}
/** The one line under a row, or null for none. Order of spec 6.3: opened none; page missing; changed; needs the file; then the identity line. */
export function sheetRowLine(input: RowLineInput): string | null;
export function chooseFileTitle(changed: boolean, web: boolean): string;
```
Rules (web): `opened` -> null. `missingPage !== null` -> `Page {k} is not in the file. Remove this sheet, or choose another file.` `changed` -> `The PDF changed after it was added. Click Choose file… and use the new file.` (`CHANGED_ROW_LINE`). `!canOpen` -> `The browser needs this PDF file again. Click Choose file…` Else `status === 'not-stamped'` -> `statusHint('not-stamped')`; `status === 'not-opened'` -> `statusHint('not-opened')`; else null. Not web (desktop): `status === 'not-stamped' || 'not-opened'` -> `statusHint(status)`, else null (exactly the old rule). `chooseFileTitle`: changed -> `The PDF changed. Choose the new file to use it.`; web -> `This browser cannot open the PDF by itself. Choose the file again.`; desktop -> `Choose the PDF file to open this sheet`.
