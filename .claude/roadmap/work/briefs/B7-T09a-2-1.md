## EXACT SHAPES

In `FlowSolveInput` add:

```ts
/** With no source and no valid entry or explicit root, treat every open end as a possible source and give each segment and fitting the highest value over all choices. Opt in; sizing and routing do not set it. */
highestWhenNoSource?: boolean;
/** Fittings that are never a root and never an open end in the highest rule: riser fittings that have no input. Ignored by the old rule. */
notOpenEndIds?: ReadonlySet<string>;
```

In `FlowResult` add:

```ts
/** The network has no source. 'highest': the highest rule gave the numbers (K is 2 or more). 'loop': a loop kept the old rule. Absent otherwise. */
noSource?: 'highest' | 'loop';
```

New exports in flow.ts:

```ts
/** The number of open ends of the network: bare fitting nodes with one segment that are not in `input.riserFittingIds` or `input.notOpenEndIds`. */
export function countOpenEnds(input: FlowSolveInput): number;
/** True when an element of category 'equipment' with own capacity not above 0 has a port in this network (only this network's elements count). */
export function networkHasSource(input: FlowSolveInput): boolean;
```

Details:
- `countOpenEnds`: build the node degrees from the segments of the network (`input.network.segmentIds` that exist in `input.segments`), using `nodeKeyOf(endpoint, input.portGroups)`, the same way `solveFlow` builds `adjacency` (each segment adds 1 to the degree of each of its two end keys). A key is an open end when it starts with `fitting:`, its degree is 1, its id is not in `input.riserFittingIds` and not in `input.notOpenEndIds`. A segment with the same node on both ends has degree 2 there, so it is not an open end. You may share one small private helper between `countOpenEnds` and `solveFlow`.
- `networkHasSource`: look only at the endpoints of the segments of this network (kind `'port'` gives `elementId`). True when some such element has `input.elementCategories?.[id] === 'equipment'` and `!((input.terminalCapacities[id] ?? 0) > 0)`. Do NOT scan all of `elementCategories` (the scene passes all stamps of the document).

Where, in `solveFlow`: after `explicitRootKey` is known (after the line `if (explicitRootKey !== undefined && isMarked(...)) explicitRootKey = undefined;` and its closing brace, flow.ts about line 136) and before `const rootKey = ...`. Condition: `input.highestWhenNoSource && explicitRootKey === undefined && entryKey === undefined && !networkHasSource(input)`. Inside:

1. Detect a loop in the level graph: segments > nodes - components (use a small union-find over `nodeKeys`, or any exact method; a segment whose two ends are one node is a loop too). If there is a loop: remember `noSource = 'loop'`, continue with the old chain unchanged, and put `noSource: 'loop'` on the final result of the old path (spread it into the object passed to `withRiserCapacity` at the end of `solveFlow`).
2. Else, if the graph has no loop and every marked fitting key in the graph (`isMarked(k)`) has degree 1 (a marked fitting with 2 or more segments turns the mode off) and K >= 1 (K = sum of `roots`): build nodes (`id` = node key, `own` = `ownCapacityOf(key, input.terminalCapacities)`, `roots` = 1 when the key is an open end per the rule above, else 0) and edges (`id` = segment id, `a`/`b` = the two node keys; use the segments of the network that exist). Call `highestFlow`. When the result is not null:
   - `segmentCapacity[id]` = `result.edge[id]` for every segment; `segmentDirection` stays null for all.
   - `fittingCapacity[fittingId]` = `result.node['fitting:' + fittingId]` for each fitting id in `input.network.fittingIds` that has a node (otherwise null).
   - `resolved: true`, `totalCapacity: result.total`.
   - `riserCapacity`: the existing `withRiserCapacity` helper gives it when `riserDemand` is given; pass 0 (this task does not use `riserDemand` in the mode; a marked fitting is a boundary with own 0 and roots 0).
   - `noSource: 'highest'` only when `result.roots >= 2`; otherwise leave the field absent.
   - Return this result.
   A `null` from `highestFlow` (for example two components) continues with the old chain, `noSource` absent.
3. K = 0 (no open end): old chain, `noSource` absent (unless step 1 found a loop).

Everything else in the old chain, the DFS, `riserFittingFlow` and the early returns stays as is. The old behavior with the flag absent or false must be byte-identical.
