# B7-T04b brief 3: shared text helpers for the riser block of the Properties panel (ui)

Read .claude/roadmap/rules.md first. Read the UX spec `.claude/roadmap/work/ux/b7-t04b-spec.md` sections 4 and 6.

GOAL: `riserCapacity.ts` gets the labels, the parts of a `CapacityView`, and a function `fittingRiserLinesOf` that gives the Properties panel its rows, tag and hints. The T05 texts do not change.

CONTEXT: T05 built `capacityViewOf(file, riser, flow, options)` (mainLine, totalLine, rows, hints, notDesignFlow, sharedLine, designFlowHint). The Properties panel of B7-T04b shows two rows for a riser fitting ("Main level", "Connected total") with the same words. The words must come from this one file so they cannot drift. The T05 pane still uses `mainLine`, `totalLine` and `hints` and its tests must stay green with no edit.

TARGETS: edit `packages/ui/src/riserCapacity.ts` and `packages/ui/src/riserCapacity.test.ts` (add tests; do not edit an existing test). No other file.

EXACT SHAPES (add; keep every existing export and its behavior):
```ts
export const MAIN_LEVEL_LABEL = 'Main level';
export const CONNECTED_TOTAL_LABEL = 'Connected total';

// CapacityView gets these new fields. For kind 'one-member': mainValue '', totalValue null, unknownReasonText null, all four flags false.
//   mainValue: 'Level 0' | 'not known yet'            (the text after `Main level: ` in mainLine)
//   totalValue: '750 m³/h (no diversity)' | 'at least 750 m³/h (no diversity)' | '750 (no diversity)'   (the text after `Connected total: ` in totalLine)
//   unknownReasonText: REASON_TEXT[reason] (e.g. 'no source level') or null (no reason found or group not unknown)
//   complete: group.complete; unknown: group.state === 'unknown'; loop: reason === 'loop'; noUnit: unit === undefined
// mainLine and totalLine are now built as `${MAIN_LEVEL_LABEL}: ${mainValue}` and `${CONNECTED_TOTAL_LABEL}: ${totalValue}`. Their text does not change.

export interface FittingRiserLines {
  /** `Riser R1` (the name of the riser). */
  heading: string;
  /** 'Not a design flow' when view.notDesignFlow, else null. */
  tag: string | null;
  /** Always two rows: Main level, Connected total. title = `${label}: ${value}`. */
  rows: { label: string; value: string; title: string }[];
  /** In this order, each only when it applies: D, E, F, G, H below. */
  hints: string[];
}

/** null for a view of kind 'one-member'. Rows: label MAIN_LEVEL_LABEL, value `Level 0` or `not known yet` or `not known yet (<unknownReasonText>)` (when the reason is known); label CONNECTED_TOTAL_LABEL, value = view.totalValue. */
export function fittingRiserLinesOf(view: CapacityView, riserName: string): FittingRiserLines | null
```
Hints, word for word (a constant each, same style as the existing hint constants):
- D (view.sharedLine is not null): the value of `view.sharedLine` unchanged.
- E (not view.complete): `Some levels have no data, so a number reads "at least". Solved capacity counts only the levels that have data. Open Manage Buildings, tab Risers, to see which levels.`
- F (view.unknown): when view.loop: `Solved capacity counts this level only. The risers make a loop. Open Manage Buildings, tab Risers, for details.` Else: `Solved capacity counts this level only until the main level is known. Open Manage Buildings, tab Risers, to set it.`
- G (view.noUnit): `This network type has no flow unit, so the numbers have no unit.` (use the existing NO_UNIT_HINT constant)
- H (view.designFlowHint is not null): the value of `view.designFlowHint` unchanged.
Note: `unknown` and `complete` are independent (a group can be unknown and complete). The T05 `hints` array and the T05 hint texts do not change.
