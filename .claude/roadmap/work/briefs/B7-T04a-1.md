1. NEW packages/render/src/riserFlowInputs.ts, a pure module:
```ts
import type { Network, RiserFlowInput } from '@mepapp/core';

export interface RiserSolveOptions {
  riserFittingIds: Set<string>;
  entryFittingId?: string;
  riserDemand: Record<string, number>;
}

export function riserSolveOptionsFor(network: Network, inputs: ReadonlyMap<string, RiserFlowInput>): RiserSolveOptions | null
```
Look only at ids in `network.fittingIds` that have an entry in `inputs` (iterate `network.fittingIds` in order). None -> return null. Else `riserFittingIds` = those ids; `entryFittingId` = first of them with role 'entry' (omit the key when there is none); `riserDemand[id] = demandBeyond`. Marked fittings that have no entry in `inputs` are not boundaries (they are simply not passed). Short doc comment, low density.
