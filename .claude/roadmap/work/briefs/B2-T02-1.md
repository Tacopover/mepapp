EXACT SHAPES
```ts
import type { QuantityProvenance, QuantityTable } from './quantities.js';
export const PROVENANCE_HEADERS = ['Building', 'Level', 'Sheet', 'Document'] as const;
export function mergeQuantityTables(parts: readonly { provenance: QuantityProvenance; tables: readonly QuantityTable[] }[]): QuantityTable[];
```
Rules:
- One result table per table name. Order: `Segments`, `Terminals`, `Equipment`, `Fittings` first (when present), then any other names in order of first use.
- Result headers: `Building`, `Level`, `Sheet`, `Document`, then the union of the other headers in order of first use (parts in order, headers in order within a table).
- A part header that equals a provenance header (case-insensitive) is renamed `<header> (custom)` (repeat " (custom)" while it still clashes with a provenance header or with another header of the same input table, case-insensitive). The rename is per input table; after the rename, columns with the same name from different parts are the same column.
- Each output row: `[provenance.building, provenance.level, provenance.sheet, provenance.document, ...cells]` where cells follow the union header order; a column the input table lacks gives `null`. Rows keep input order (parts in order). Two rows with the same Id from two parts stay two rows. A `Page` column of a part stays as a normal column.
- A name with no rows in any part gives no table. Do not change the input arrays.
