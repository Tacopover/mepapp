```ts
export interface FolderFiles {
  read(name: string): Promise<{ text: string; modifiedMs: number; sizeBytes: number } | undefined>;
  write(name: string, text: string): Promise<void>;
  list(): Promise<string[]>;
}
export const SUMMARY_SUFFIX = '.summary.json';
export function summaryFileName(projectUuid: string): string; // `${projectUuid}${SUMMARY_SUFFIX}`; throws Error if projectUuid is empty or contains / \ : or '..' or any char outside [A-Za-z0-9_-] (a uuid is safe)
export class FolderBuildingStore implements BuildingStore {
  constructor(files: FolderFiles, buildingFileName: string);
  capabilities: persistent true, needsUserGesture false, shareable true, worksOffline true.
  status(): 'ready'; requestAccess(): 'ready';
  read(): reads buildingFileName; returns { json: text, revision: `${modifiedMs}:${sizeBytes}` } or undefined.
  write(json, expectedRevision?): re-read the file now; checkRevision(buildingFileName, expectedRevision, current revision or undefined); write; re-read to get the new revision; return it. If the new read is undefined throw Error.
  readSummary(projectUuid): text of summaryFileName or undefined.
  writeSummary(projectUuid, json): files.write(summaryFileName(...), json).
  listSummaries(): files.list() filtered to names ending SUMMARY_SUFFIX, strip the suffix, sort.
}
```
Revision caveat to put in a one-line code comment: two writes within one ms with equal size give equal revisions; accepted.
Test file: an in-memory `FolderFiles` (Map name -> text, a fake clock that advances modifiedMs by 1 on each write, size = text length) and run `runBuildingStoreContract('FolderBuildingStore', ...)` from './contract/building-store.contract.js'. Note: a same-length rewrite must still give a new revision, so the fake clock must advance. Add own tests: listSummaries ignores the building file and other files; summaryFileName rejects '../x', 'a/b', ''; revision string equals `${modifiedMs}:${sizeBytes}`.
