Read .claude/roadmap/rules.md first. Standing rule: if reality does not match this brief, stop and report BLOCKED or NEEDS_CONTEXT. Do not work around it. No `pnpm add`, no prettier, no chained Bash, no heredocs, no `window.confirm`. Work only in /root/MepApp/.claude/worktrees/buildings-model.

## GOAL
Add pure, tested functions in `@mepapp/ui`: the recent-buildings list (localStorage key `mepapp.buildings.v2`) and `importOldRegistry` that converts the old v1 registry (`Building[]`) to `BuildingFile[]`. No UI surface is added.

## CONTEXT
`packages/ui/src/buildings.ts` holds the old registry (`Building {id,name,levels: BuildingLevel[]}`, `BuildingLevel {id,name,documentFileName: string|null}`, key `mepapp.buildings.v1`). KEEP all old exports unchanged: `Building`, `BuildingLevel`, `loadBuildings`, `saveBuildings`, `newBuilding`, `newLevel`, `assignDocumentToLevel` (`ManageBuildingsDialog.tsx` and `App.tsx` use them). `@mepapp/core` exports `BuildingFile`, `BuildingSheet`, `emptyBuilding(id, name)` and `BuildingLevel` (core type: `{id,name,elevationMm}`; import it as `BuildingLevel as CoreBuildingLevel` to avoid a name clash). Check `packages/core/src/index.ts` exports these; if not, stop (NEEDS_CONTEXT). A `BuildingSheet` is `{ id; levelId; projectUuid: string|null; pageIndex: number; displayName; location: { fileName } }`. See other storage modules (e.g. `routeAreaStorage.ts` and its test) for style: they take an optional storage argument.

## EXACT SHAPES
```ts
// recentBuildings.ts
export interface RecentBuilding { id: string; name: string; location: string }
export const RECENT_BUILDINGS_KEY = 'mepapp.buildings.v2';
export const RECENT_BUILDINGS_MAX = 20;
type StorageLike = Pick<Storage, 'getItem' | 'setItem'>;
/** Bad JSON, a non-array, or entries without string id/name/location give [] / drop the entry. */
export function loadRecentBuildings(storage?: StorageLike): RecentBuilding[];   // default globalThis.localStorage
export function saveRecentBuildings(list: RecentBuilding[], storage?: StorageLike): void;
/** Puts entry first; removes an older entry with the same id; keeps at most RECENT_BUILDINGS_MAX. Pure. */
export function addRecentBuilding(list: RecentBuilding[], entry: RecentBuilding): RecentBuilding[];
export function removeRecentBuilding(list: RecentBuilding[], id: string): RecentBuilding[];
```
```ts
// buildings.ts (added)
/** Each old Building becomes an empty BuildingFile with the same id and name. Each old level keeps its id and name with elevationMm = 0. A level with documentFileName becomes one sheet: id `${level.id}-sheet`, levelId, projectUuid null, pageIndex 0, displayName = documentFileName, location { fileName: documentFileName }. Pure; does not touch localStorage. */
export function importOldRegistry(v1: Building[]): BuildingFile[];
```
