## GOAL
Add an in-memory dev building store that wraps `MemoryBuildingStore`, and a dev-only hook `window.__mepBuilding` that exists only when `import.meta.env.DEV` is true.

## CONTEXT
`MemoryBuildingStore` (packages/platform/src/memory/memory-building-store.ts) takes `constructor(initial?: { json: string; summaries?: Record<string,string> })` and is exported from `@mepapp/platform`. `BuildingStore` interface is in packages/platform/src/building-store.ts (status, requestAccess, read, write, readSummary, writeSummary, listSummaries, capabilities). `apps/web/src/main.tsx` builds the app; it has no `import.meta.env` use yet (`apps/web/src/vite-env.d.ts` exists). A production build must not contain the string `__mepBuilding`.

## EXACT SHAPES
```ts
// dev-building-store.ts
import { MemoryBuildingStore, type BuildingStore } from '@mepapp/platform';
export interface DevBuildingStore extends BuildingStore {
  /** Replaces the held building and summaries. Revision restarts. */
  load(json: string, summaries?: Record<string, string>): void;
}
export function createDevBuildingStore(): DevBuildingStore;
```
Implementation: hold `inner: MemoryBuildingStore` (initially `new MemoryBuildingStore()`); `load` sets `inner = new MemoryBuildingStore({ json, summaries })`; every BuildingStore member delegates to the current `inner` (`capabilities` as a getter).

In main.tsx, before `createRoot` is reached (top level, after the imports), add:
```ts
if (import.meta.env.DEV) {
  void import('@mepapp/platform-web/dev').then(...)
}
```
Do NOT use a subpath export unless it already exists. Simpler: import `createDevBuildingStore` from `@mepapp/platform-web` statically and write
```ts
if (import.meta.env.DEV) {
  const devBuildingStore = createDevBuildingStore();
  (window as unknown as { __mepBuilding: unknown }).__mepBuilding = {
    load: (json: string, summaries?: Record<string, string>) => devBuildingStore.load(json, summaries),
    read: () => devBuildingStore.read(),
    store: devBuildingStore,
  };
}
```
Vite replaces `import.meta.env.DEV` with `false` in production and drops the block. `read` and `store` are additions to the plan signature so a check can read state back; keep them.
