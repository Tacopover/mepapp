Network types on stamps

A placement rule gives a network type to each port of the stamps that it places. Routing (a later part) uses this network type to find the ports that it must connect. Choose an example stamp and a layout of the rule guide. Click a stamp in the drawing to see its Properties.

A port with a network type and no segment shows a dot in the color of its network type. The dot shows in MepApp only, not in the PDF export.

What this mockup shows

  • The rule holds the network type. A room type does not hold one: a room type has no stamp and no ports, and a rule that counts by coverage or the same number in each room has no need of a room type.
  • Each built-in need gives a default: Supply air → Supply Air, Return air → Return Air, Heating → Heating Water, Cooling → Chilled Water. Light, Sockets and own needs give none.
  • A stamp with 2 or more ports can give each port its own network type. A stamp without ports of its own uses its center point.
  • The placed stamp keeps a network type for each port. Properties shows it and can change it. A change marks an auto-placed stamp as moved, so a new run of Auto-place keeps it.
  • A segment with another network type on a port gives a mark in the drawing and a line in Properties. MepApp does not change the segment or the port on its own.
